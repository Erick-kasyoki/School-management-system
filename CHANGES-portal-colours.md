# Coloured portal cards (portal.html)

The four sign-in cards are no longer white. Each has its own colour gradient, matching its portal:
Student = blue, Parent = pink, Teacher = orange, Administrators = green.
The icon sits in a white tile, the title is white, and SIGN IN is a white button with the card's colour. Cards lift slightly on hover.

To change a colour, edit `.card.student / .parent / .teacher / .admin { --c: ... }` in the <style> block of portal.html.
The Service Providers box is unchanged. File: portal.html.
